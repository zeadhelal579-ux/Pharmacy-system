# اختبار نسخة العرض والتشغيل المتكامل

**الحكم المحلي:** الديمو جاهز للعرض. الفرونت المتصل والـAPI وSQL Server اجتازوا اختبارات التكامل على LocalDB. جاهزية تشغيل فرع إنتاجي خارج التحقق ده.

تم الاختبار في 14 نوفمبر 2026 على Node.js 24 و.NET 10 وMicrosoft Edge وSQL Server LocalDB. قاعدة التكامل وقاعدة تحقق تسجيل الدخول اتعملوا ببيانات منفصلة. نسخة React المتصلة استخدمت Vite Preview ومررت الطلبات للباك. نسخة الديمو استخدمت build مستقل وبيانات المتصفح.

## إصلاحات قبل الرفع

- **اعتماديات NuGet.** تم تثبيت `System.Security.Cryptography.Pkcs` على `9.0.21` بدل النسخة غير المباشرة `9.0.4` التي ظهر عليها تنبيهان. الفحص بعد التحديث أفاد بعدم وجود حزم متأثرة حسب المصادر المتاحة، و`npm audit` أبلغ عن صفر تنبيهات لنسختي الفرونت.
- **رد الأخطاء.** تم استبدال رسالة الاستثناء الداخلية برسالة عامة ومعرّف تتبع. فحص المصدر والبناء أكدوا التغيير. لم يُحقن خطأ عمدًا لاختبار فرع الاستثناء في بيئة الإنتاج.
- **تسجيل الدخول.** أُضيف حد للطلبات لكل عنوان IP. حد 30 طلبًا عطّل حالتين سليمتين في تشغيل التكامل المتسلسل، فاتضبط الافتراضي إلى 60. اختبار مستقل بحد 2 أكد قبول حساب صحيح، رفض كلمة مرور خاطئة، ثم رد 429 عند استهلاك الحد. توزيع العناوين خلف proxy وعدد النسخ يحتاج ضبط حسب الاستضافة.
- **ترويسات الديمو.** أُضيفت CSP ومنع التضمين وفحص MIME وسياسة referrer في Vercel. اختبار Edge شغّل ترويسات المستند محليًا وعبر سيناريوهات العرض بدون أخطاء JavaScript.

## حدود المراجعة الدفاعية

تمت مراجعة الهوية والأدوار وتخزين كلمات المرور **01/05/09**، والإعدادات والاعتماديات والملفات العامة **02/11/20/21/22/23/24/25**، والتحقق من المدخلات وReact escaping وحد الدخول وCORS وترويسات العرض **06/07/12/13/14/18**، وEF Core والتسعير والتدقيق **03/08/10/19/26/27** حسب المصدر والاختبارات المتاحة. Cookies وCSRF المبني على cookies واسترداد كلمة المرور **15/16/17** خارج خصائص النسخة. HTTPS عبر استضافة فعلية **04** ومراقبة الإنتاج وأداء النسخ المتعددة لم يتختبروا. حسابات الديمو والمحاكاة على المتصفح مصممة للتجربة ببيانات خيالية.

## إعادة الاختبار

```powershell
npm ci --prefix tests-audit
npm run build --prefix front-end/pharmacy-web
dotnet build back-end/PharmacyERP/PharmacyERP.slnx
pwsh -NoProfile -File tests-audit/Run-Integration.ps1 -Browser msedge -Width 390 -BackupRestore
```

لتكرار اختبار الديمو، شغّل `npm run preview` من مجلد الديمو بعد البناء. من جذر المشروع شغّل `node tests-audit/demo-smoke.cjs`. اضبط `PHARMACY_DEMO_ORIGIN` لو الـpreview على عنوان غير `http://127.0.0.1:5173`. الاختبار يبدأ كل مرة بمتصفح نظيف، ويراجع إعادة التحميل وإعادة ضبط البيانات.
