# PharmacyERP Demo

ديمو React للصيدلية بفرعين ومخزن مركزي و12 صنف و8 فواتير جاهزين للتجربة. اضغط على الدور وسجّل دخول فورًا. التغييرات بتتحفظ محليًا في المتصفح، والدور الحالي في نفس التبويب. زر **تغيير الدور** بيرجعك لاختيار الحساب، و**استرجاع بيانات الديمو** بيرجع الرصيد والفواتير والحسابات لحالة البداية.

## جرّب إيه

| الدور | سيناريو |
|---|---|
| كاشير | شيفت مفتوح جاهز. امسح `62009901` لبيع علبة باراسيتامول بـ32 جنيه، واعرض الفاتورة أو اعمل مرتجع. |
| مسؤول المخزن | اعتمد تحويل `#401` واشحنه من المخزن. الحجز بيأثر على المتاح، والشحن بيخصم الرصيد. |
| مدير الفرع | استلم التحويل في المعادي كصالح أو تالف أو عجز. اعتمد الجرد أو الخصم أو استلم من أمر شراء. |
| مدير النظام | افتح تتبع الدفعات وجرب الدفعة `RX-2402`. تقدر تشوف رصيدها والفاتورة والتحويل، أو تراجع سجل التدقيق والمطابقة وتدير المستخدمين. |

## تنظيم الملفات

- `src/` يحتوي على شاشات React ومساراتها.
- `src/demo/DemoLogin.tsx` و`demo.css` لصفحة اختيار الدور وتصميمها.
- `src/demo/roles.ts` للأدوار والفروع و`seed.ts` لبيانات البداية.
- `src/api.ts` بيحمّل محاكاة الطلبات من `src/demo/dispatch.ts` عند أول استعلام. ملفات `sales.ts` و`inventory.ts` و`supply.ts` و`reports.ts` بتطبق سيناريوهات العرض.
- `src/demo/store.ts` لحفظ بيانات كل متصفح واسترجاعها. الأدوار وعمليات الدفع محاكاة عرض، والواجهة تعمل بدون API أو قاعدة بيانات خارجية.

## التجربة المحلية

```sh
npm ci
npm run lint
npm run build
npm run preview
```

استخدم Node.js 24 وافتح عنوان Vite Preview. ينفع تفتح مسار فاتورة وتعمل refresh في نفس التبويب. `npm run dev` يشتغل أثناء تعديل الكود.

## Vercel

اختار الريبو واضبط **Production Branch** على `front-Deploy`. سيب **Root Directory** على جذر الفرع لأن `package.json` و`vercel.json` موجودين فيه.

الملف [vercel.json](vercel.json) يحدد Vite و`npm ci` و`npm run build` ومجلد `dist`. فيه تحويل داخلي لـ`index.html` عشان المسارات زي `/pos` و`/receipts/1001` تفتح مباشرة، وترويسات لمحتوى النسخة الثابتة. اختار Node.js 24.x. إعدادات Environment Variables تقدر تسيبها فارغة.
